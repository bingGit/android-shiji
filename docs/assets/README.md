# 拾记 Chrome 扩展资源

## v0.1.0

- 下载：[shiji-chrome-extension-0.1.0-chrome.zip](./shiji-chrome-extension-0.1.0-chrome.zip)
- 构建版本：`0.1.0`
- 适用浏览器：Chrome 114 及以上
- 安装方式：打开 `chrome://extensions`，启用“开发者模式”，选择“加载已解压的扩展程序”。下载 ZIP 后请先解压，再选择解压后的目录。
- 源码仓库：[bingGit/shiji-chrome-extension](https://github.com/bingGit/shiji-chrome-extension)

该 ZIP 是 Chrome Manifest V3 构建产物，包含侧边栏、网页摘录、当前页面保存和本地同步队列等功能。
